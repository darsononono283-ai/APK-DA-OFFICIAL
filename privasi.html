Kebijakan Privasi

Halaman ini menjelaskan secara ringkas penggunaan data pada APK DA•OFFICIAL.

Data dan penyimpanan

Daftar favorit, playlist, serta riwayat musik dapat disimpan secara lokal di browser perangkat. Fitur yang memakai Supabase mengirim permintaan ke layanan backend yang dikonfigurasi oleh pengelola.

Tautan pihak ketiga

Website dapat memuat tautan ke situs atau file pihak ketiga. Kebijakan dan praktik privasi situs tersebut diatur oleh masing-masing penyedia.

Keamanan

Jangan masukkan kata sandi, kode OTP, atau informasi pembayaran ke kolom yang tidak berkaitan. Pengelola perlu menjaga konfigurasi backend dan tidak boleh menaruh kunci rahasia server di file publik.

Kontak

Untuk pertanyaan terkait website, gunakan kanal resmi yang disediakan pengelola.
